# Bank Loan Analysis Dashboard

## Project Overview
This project focuses on analyzing bank loan data to understand loan applications, funded amounts, borrower profiles, and loan repayment performance. The objective is to generate meaningful business insights and support data-driven lending decisions.

## Tools & Technologies
- **Microsoft Excel:** Initial data inspection and analysis
- **Power Query:** Data cleaning and transformation
- **MySQL:** Data analysis using SQL queries
- **Power BI:** Interactive dashboard development

## Project Workflow
1. Imported and explored the raw bank loan dataset.
2. Cleaned and transformed data using Excel and Power Query.
3. Performed data analysis using MySQL.
4. Created an interactive dashboard using Power BI.
5. Identified trends and patterns in loan applications and repayment performance.

## Key Business Questions
- What is the total number of loan applications?
- What is the total loan amount funded?
- What is the total amount received?
- What percentage of loans are good loans and bad loans?
- Which loan purposes have the highest application volume?
- Which employment categories have the most loan applications?
- How does home ownership affect loan distribution?
- Which states have the highest loan applications?
- How do interest rates and debt-to-income ratios relate to loan performance?

## Dashboard KPIs
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Good Loan Percentage
- Bad Loan Percentage
